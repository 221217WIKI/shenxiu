神修尼亚 · 免费云端部署（0 元，不需要信用卡）
================================================

用到的三个免费服务：
1. GitHub     —— 存代码（你已有账号 221217WIKI）
2. MongoDB Atlas —— 存数据（免费 512MB，永久，不需要信用卡）
3. Render     —— 跑服务（免费 512MB 内存，不需要信用卡，支持 WebSocket）

全套 0 元。代价：完全没人访问 15 分钟后会睡一会，下次有人来要等约 1 分钟。


第一步：GitHub 建仓库
--------------------
1. 打开 github.com，登录你的账号
2. 右上角 + → New repository
3. Repository name 填：shenxiu
4. 选 Public（免费），点 Create repository
5. 页面上点 "uploading an existing file" 链接
6. 把「神修尼亚_上传GitHub」文件夹里的**所有文件和文件夹**拖进去
   （download 文件夹要一起拖，里面有 APK）
7. 底部点 Commit changes


第二步：MongoDB Atlas 建免费数据库
---------------------------------
1. 打开 mongodb.com/cloud/atlas/register，用邮箱注册（不用信用卡）
2. 登录后点 Build a Database → 选 M0 FREE → 区域选 Singapore → Create
3. 创建时会让你建数据库用户：
   - Username 填：shenxiu
   - Password 自己设一个（记下来，只能用字母数字）
4. 建好后点 Connect → Drivers → 复制那串连接地址，长这样：
   mongodb+srv://shenxiu:你的密码@cluster0.xxxxx.mongodb.net/?retryWrites=true&w=majority
   （把里面的 <password> 换成你设的密码）
5. 左侧 Security → Network Access → Add IP Address → 选 ALLOW ACCESS FROM ANYWHERE
   （不设这个，Render 连不上数据库）
6. 把这串地址存好，下一步要用


第三步：Render 部署
------------------
1. 打开 render.com，点 Get Started，用 GitHub 账号登录（不用填信用卡）
2. 点 New + → Web Service
3. 选 Connect a repository → 找到 shenxiu 仓库 → Connect
4. 页面会自动读到仓库里的 render.yaml，配置基本已经填好
5. 在 Environment Variables 里加两个：
   - MONGODB_URI = 第二步复制的那串地址
   - ADMIN_KEY = 你想用的后台密钥（例如 admin-888888）
6. 点 Create Web Service / Deploy
7. 等 2-5 分钟，状态变成 Live 后，页面上方会显示你的网址：
   https://shenxiu-xxxx.onrender.com
8. 打开这个网址，看到神修尼亚下载页就是成功了


第四步：告诉卖家（也就是我）
--------------------------
把 https://xxx.onrender.com 这个网址发我，我做两件事：
1. 把它写进安卓 APK 的内置地址，重新打包给你
2. 把 robots.txt 和 sitemap.xml 里的占位域名换成这个真实网址


第五步：让浏览器能搜到「神修尼亚」（重要）
----------------------------------------
网站上线后，要主动提交给搜索引擎，否则搜不到：

百度（国内用户主要用这个）
1. 打开 百度搜索资源平台（ziyuan.baidu.com），注册登录
2. 用户中心 → 站点管理 → 添加网站 → 填你的 onrender.com 网址
3. 验证方式选「文件验证」，按提示下载验证文件，放进 GitHub 仓库根目录
4. 验证通过后 → 普通收录 → 提交网址：把你的首页地址粘进去提交
5. 再提交 sitemap：https://你的域名/sitemap.xml

Bing（国内也能用）
1. 打开 bing.com/webmasters，注册
2. 添加站点 → 提交 sitemap

Google（如果要做海外）
1. 打开 search.google.com/search-console
2. 添加资源 → 提交 sitemap

提交之后：
- 一般 3-7 天开始有收录，新站可能要 2-4 周
- 想更快被搜到，域名要稳定可访问（免费层会休眠，建议偶尔访问一下保持活跃）
- 想在国内搜"神修尼亚"排前面，后期需要买正式域名（30-60 元/年）+ 备案


常见问题
--------
1. Render 显示 Deploy failed：多半是 MONGODB_URI 填错，检查密码里有没有特殊字符
2. 打开网页显示 Internal Server Error：看 Render 的 Logs 最后几行
3. 数据没了：确认 MONGODB_URI 已填；没填的话数据存在临时磁盘，重启就清空
4. 图片发出去重启后打不开：免费层磁盘不持久，这是已知限制，后续我再补
5. 后台进不去：ADMIN_KEY 必须和你在 Render 里填的一致
